# OpenAPI

The OpenAPI schema is generated by FastAPI from the running application.

- Interactive API: `http://localhost:8000/docs`
- OpenAPI JSON: `http://localhost:8000/openapi.json`
- ReDoc: `http://localhost:8000/redoc`

The current API includes OTP authentication, server-side sessions, mapping-rule management, rule simulation, and the signed Service A inbound webhook.
